# Anime Manager 📺

A lightweight CLI application in Python for tracking and managing your anime list.

## Features

- **Add & Remove**: Manage anime titles easily with duplicate protection.
- **Search**: Case-insensitive title search.
- **Text File Persistence**: Save and reload your list dynamically from `anime.txt`.

## Quick Start

Run `main.py`:
```bash
python main.py
```

## Structure

```
anime-manager/
├── main.py          # Interactive menu interface
├── anime_manager.py # Logic for list management & storage
├── anime.txt        # Text storage file
├── .gitignore
└── README.md
```
